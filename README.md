## 📊 Customer Churn Analysis Dashboard (Power BI) 
**Tools:** Power BI, SQL, Power Query, DAX 
**Year:** 2026 
### Overview This project analyzes customer churn behavior and its impact on revenue, with the aim of identifying high-risk customer segments and improving retention strategies.
### Key Insights 
- Churn rate identified at **26.5%**
- Month-to-month contracts had the **highest churn risk**
- Customers within **0–12 months tenure** showed the highest likelihood of churn
- Certain payment methods were linked to increased churn behavior
### What I Did
- Cleaned and transformed raw customer data using Power Query
- Created calculated KPIs including churn rate and revenue at risk using DAX
- Segmented customers using SQL (contract type, tenure, payment method)
- Built an interactive dashboard with filters and drill-down analysis
### Business Impact
Provided actionable insights to support customer retention strategies and reduce revenue loss from high-risk customer groups.
